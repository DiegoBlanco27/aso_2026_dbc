# Practica 1: Administración Remota con Powershell 
- Vamos a realizar tareas de administración remota de un servidor en modo Core utilizando Powershell.
## Entorno Virtualizado
Usaremos las siguientes maquinas virtuales:
- Windows Server 2019 con entorno grafico, se llamara DBC-2019
- Windows Server 2019 en modo Core, se llamara DBC-CORE-2019
- Windows Server 2019 en modo Core, se llamara DBC-CORE-2019-2

Los equipos tendran un adaptador solo-anfitrion cada uno en la misma red

Editaremos el fichero host de cada equipo para habilitar la resolucion local de nombres entre ellos, el fichero se encuentra en la ruta C:\Windows\System32\drivers\etc y lo editaremos con el bloc de notas, abajo del todo añadiremos la ip y el nombre de los otros equipos

En los servidores Core, abriremos PowerShell, nos dirigiremos a ```C:>``` y ejecutamos el comando ```cd \Windows\System32\drivers\etc``` y a continuacion el comando ```notepad.exe host``` y añadimos la ip y el nombre del servidor con interfaz grafica en mi caso ``` 192.168.56.104 DBC-2019 ```


## Configuración del acceso remoto al nuevo equipo

Ejecutaremos el comando ```Enable-PSRemoting -Force``` en los servidores para que podamos usar PowerShell Remoting en ellos

Luego, ejecutaremos el comando ```Set-NetFirewallProfile -Profile Domain, Public, Private -Enabled False``` para que el cortafuegos no nos de problemas a la hora de conectarnos

Añadiremos el equipo con entorno grafico en los TrustedHosts de los otros servidores para ello usaremos el comando ```Set-Item WSMan:\localhost\Client\TrustedHosts -Value "192.168.56.104"``` para que vean al otro equipo como un dispositivo de confianza

Ahora, usaremos el comando ```Enter-PSSession -ComputerName 192.168.56.103 -Credential (Get-Credential)``` para conectarnos desde el entorno grafico a uno de los servidores Core, nos pedira un usuario y una contraseña y usaremos los del administrador.

## Configuración del acceso remoto sobre HTTPS

Si todo va bien, estaremos conectados al otro equipo de forma remota, desde él, crearemos un certificado digital que pasaremos al equipo local, para que cuando nos queramos conectar de forma remota no nos pida credenciales, es decir que confie en nosotros.

1. Primero, crearemos el certificado con el comando ```New-SelfSignedCertificate -DnsName "192.168.56.104" -CertStoreLocation Cert:\LocalMachine\My -KeyLength 2048```
2. Ahora, exportaremos el certificado: ```Export-Certificate -Cert Cert:\LocalMachine\My\<HUELLA_HEXADECIMAL> -FilePath C:\servercert.cer```
3. Ahora lo copiaremos a una carpeta compartida entre el servidor y el cliente, yo por ejemplo, la llamare 'compartida' y la pondre en el equipo local, para copiarla usaremos el comando ```Copy-Item -Path C:\servercert.cer -Destination "\\192.168.56.104\compartida\"```
4. Por ultimo, solo nos faltara exportar el certificado a el directorio donde se guardan todos los certificados del sistema, ```Import-Certificate -FilePath C:\compartida\servercert.cer -CertStoreLocation Cert:\LocalMachine\Root```
5. A partir de ahora cuando usemos el comando ```Invoke-Command``` o ```Enter-PSSession``` si le añadimos ```-UseSSL``` no nos pedira credenciales, es decir nos conectaremos de forma transparente.

## Windows Admin Center (WAC)
WAC es una herramienta de Microsoft con la que se pueden administrar varios equipos o servidores desde el mismo equipo desde un navegador web a traves de una interfaz grafica.
- La ruta para entrar en Windows Admin Center es (https://<Nombre_o_IP_del_Servidor>:<Puerto>) en este caso ```https://192.168.56.104:433``` para poder gestionar el otro equipo desde WAC solamente tendremos que añadirlo seleccionando la opcion 'Agregar' y posteriormente 'Agregar Servidores' escribimos el nombre del equipo (DBC-CORE-2019) y se añadira a la lista de servidores automaticamente, permitiendonos administrarlo desde ahi
