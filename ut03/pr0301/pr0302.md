# Practica 2: Condicional ```if```
Vamos a realizar las siguentes tareas usando ```if``` en los scripts:

## Ejercicio 1: Contar lineas de un archivo
```
#!/bin/bash

read -p "Introduce el nombre del archivo: " archivo

if [ -f "$archivo" ]; then
    lineas=$(wc -l < "$archivo")
    
    echo "El archivo $archivo tiene $lineas líneas."
else
    echo "El archivo archivo no existe"
fi
```

## Ejercicio 2: Verificación de archivo
```
#!/bin/bash

read -p "Introduce la ruta del archivo: " archivo

if [ -e "$archivo" ] then
    echo "El archivo existe."

    if [ -r "$archivo" ] then
        echo "Tienes permisos de lectura sobre el archivo."
    else
        echo "No tienes permisos de lectura para este archivo."
    fi
else
    echo "El archivo no esta en esta ruta."
fi
```

## Ejercicio 3: Comparación de dos números
```
#!/bin/bash

read -p "Introduce un número: " num1
read -p "Introduce otro número: " num2

if [ $num1 -gt $num2 ] then
    echo "El número $num1 es mayor que el número $num2"
elif [ $num2 -gt $num1> ] then
    echo "El número $num2 es mayor que el número $num1"
else
    echo "Es el mismo número"
fi
```
