# Practica 3: Parámetros en Bash 
Vamos a realizar las siguentes tareas con parámetros en Bash:
1. Crea un script que funcione como una calculadora de operaciones básicas:
   ```
    #!/bin/bash

    primero=$1
    operacion=$2
    segundo=$3

    if [ -z $primero ] || [ -z $operacion ] || [ -z $segundo ]; then
        read -p "Introduce el primer número: " primero
        read -p "Introduce la operación: " operacion
        read -p "Introduce el segundo número: " segundo
    fi

    resultado=$(( $primero $operacion $segundo ))
    echo "$primero $operacion $segundo = $resultado"
   ```

2. Crea un script que verifique si una dirección IP es válida:
   ```
    #!/bin/bash

    IP=$1

    if [ -z $IP ]; then
        read -p "Introduce una IP: " IP
    fi

    if  echo $IP | grep -E "^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}$" ; then
        echo "La IP $IP es válida."
    else
        echo "La IP no es válida."
    fi
   ```

3. Crea un script que cuente archivos de distintos tipos en un directorio:
   ```
    #!/bin/bash

    dir=$1

    if [ -z $dir ]; then
        read -p "Introduce el directorio: " dir
    fi

    if [ ! -d $directorio ]; then
        echo "El directorio no existe."
        exit 1
    else
        echo "Archivos agrupados por extensión en: $dir"

        find "$dir" -type f | grep -E '\.[^./]+$' |
        while read -r archivo; do
            extension=".${archivo##*.}"
            echo "archivos $extension"
        done | sort | uniq -c
    fi
   ```

4. Crea un script que realice una copia de seguridad de un directorio:
   ```
    #!/bin/bash

    origen=$1
    destino=$2

    fecha=$(date +%Y%m%d)

    if [ -z $destino ]; then
        read -p "Introduce un directorio origen: " origen
        read -p "Introduce un directorio destino: " destino
    fi

    if [ -d $directorio ] && [ -d $destino  ]; then
        tar -cvzf $destino/backup$fecha.tar.gz $origen/*
        echo "backup creado en $destino" 
    else
        echo "El directorio origen o el destino no existe"
    fi
   ```

5. Crea un script que convierta una temperatura entre Celsius y Fahrenheir:
   ```
    #!/bin/bash

    temperatura=$1
    unidad=$2

    if [ -z $temperatura ]; then
        read -p "Introduce la temperatura: " temperatura
    fi

    if [ -z $unidad ]; then
        read -p "Introduce la unidad (C/F): " unidad
    fi

    if [ $unidad = "F" ]; then 
        resultado=$(( ($temperatura - 32) * 5/9 ))
        echo "$temperaturaº$unidad = $resultadoºC"
    elif [ $unidad = "C" ]; then
        resultado=$(( ($temperatura * 9/5) + 32 )) 
        echo "$temperaturaº$unidad = $resultadoºF"
    else 
        echo "Introduce una unidad valida"
    fi
   ```

6. Crea un script que genere un nombre aleatorio para un archivo:
   ```
    #!/bin/bash

    extension=$1

    if [ -z $extension ]; then
        read -p "Introduce una extension (sin punto): " extension
    fi

    nombre=$(tr -dc 'a-z0-9' < /dev/urandom | head -c 4)

    archivo="$nombre.$extension"

    echo "Archivo creado con el nombre $archivo"
   ```

8. Crea un script que genere un numero aleatorio entre un mínimo y un máximo:
   ```
    #!/bin/bash

    min=$1
    max=$2

    if [ -z $min ]; then
        read -p "Indica el número minimo: " min
    fi

    if [ -z $max ]; then
        read -p "Indica el número máximo: " max
    fi

    rango=$(( max - min ))
    num=$(( (RANDOM % rango) + min ))

    echo "Número generado: $num"
   ```
