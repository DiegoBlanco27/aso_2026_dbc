# Practica 2: Variables, tipos de datos y colecciones en Powershell
## Bloque 1: Tipado dinámico, estático y tipos básicos
1. **Comprobando el tipado dinámico**
   - Declara una variable llamada ```$recurso``` y asígnale el valor numérico ```8080```. Muestra por pantalla el nombre de su tipo de dato. A continuación, en la línea siguiente, asígnale la cadena ```"Puerto HTTP"``` a esa misma variable y vuelve a mostrar su tipo de dato.
   ```
      $recurso = 8080
      $recurso.GetType().Name

      $recurso = "Puerto HTTP"
      $recurso.GetType().Name
   ```

2. **Forzando el tipado estático**
   - Declara con tipado estático una variable entera llamada ```$maxConexiones``` con valor ```100``` y una variable booleana llamada ```$firewallActivo``` con valor ```$true```. Escribe en un comentario qué error exacto devuelve PowerShell si intentas ejecutar ```$maxConexiones = "Cien"```.
   ```
      [int]$maxConexiones = "Cien"
      [bool]$firewallActivo = $true

      No se puede convertir el valor "Cien" al tipo "System.Int32". Error: "La cadena de entrada no tiene el formato correcto."
   ```
3. **Números grandes y precisión financiera**
   - Declara una variable ```$tamanoBackup``` que almacene el valor de 2 Terabytes expresado en bytes (```2199023255552```) forzando el tipo ```Int64``` mediante su sufijo correspondiente (```L```) o mediante cast ```[long]```.
   - Declara dos variables de alta precisión (```[decimal]``` o sufijo ```d```): ```$costeLicencia = 149.95d``` y ````$iva = 31.49d```. Calcula la suma de ambas en ```$totalFactura``` y muéstrala por pantalla.
   ```
      [long]$tamanoBackup = 2199023255552L

      [decimal]$costelicencia = 149.95d
      [decimal]$iva = 31.49d
      [decimal]$totalfactura = $costelicencia + $iva

      $totalfactura
   ```

4. **Cálculo de tiempos de ejecución (```DateTime``` y ```TimeSpan```)**
   - Guarda la fecha y hora actual en ```$fechaActual```. Muestra por pantalla un mensaje que indique el año actual (```.Year```) y la fecha exacta en la que caducará una contraseña si vence dentro de 45 días (```.AddDays()```).
   - Simula una tarea midiendo su duración: captura la fecha en ```$inicio```, ejecuta una pausa de 3 segundos con ```Start-Sleep -Seconds 3```, captura la fecha en ```$fin``` y almacena la resta de ambas en una variable de tipo ```[TimeSpan]$tiempoTotal```. Muestra por pantalla los segundos totales transcurridos (```.TotalSeconds```).
   ````
      $fechaActual = Get-Date

      Write-Host "El año actual es: $($fechaActual.Year)"

      $fechaCaducidad = $fechaActual.AddDays(45)
      Write-Host "La contraseña caducará el: $fechaCaducidad"

      $inicio = Get-Date

      Start-Sleep -Seconds 3

      $fin = Get-Date

      [TimeSpan]$tiempoTotal = $fin - $inicio

      Write-Host "Tiempo total transcurrido: $($tiempoTotal.TotalSeconds) segundos"
   ```

## Bloque 2: Manipulación de cadenas y expresiones regulares
5. **Comillas simples, dobles y subexpresiones**
   - Declara ```$servicio = "Spooler"``` y ```$fecha = Get-Date```.
   - Muestra con ```Write-Host``` una frase con comillas simples donde aparezca literalmente ```$servicio```.
   - Muestra otra frase con comillas dobles que expanda el valor de ```$servicio``` y además muestre solo el día del mes (```$($fecha.Day)```) usando una subexpresión ```$()```.

   ```
      $servicio = "Spooler"
      $fecha = Get-Date

      Write-Host 'Estado del servicio $servicio a las $fecha'
      Write-Host "El servicio $servicio se ejecuto el dia $($fecha.Day) del mes."

      Resultado:
         Estado del servicio $servicio a las $fecha
         El servicio Spooler se ejecuto el dia 4 del mes.
   ```

6. **Operador de formato (```-f```) y *Here-Strings***
   - Utilizando el operador ```-f```, construye y muestra la cadena ```"El servidor {0} con IP {1} tiene un uso de CPU del {2}%"``` pasándole los valores ```"SRV-WEB01"```, ```"10.0.1.15"``` y ```85```.

   - Crea una variable ```$alertaCorreo``` usando un bloque **Here-String** (```@" ... "@```) de varias líneas que redacte un aviso técnico al administrador incluyendo las variables anteriores.

   ```
      $servidor = "SRV-WEB01"
      $ip = "10.0.1.15"
      $cpu = 85

      Write-Host ("El servidor {0} con IP {1} tiene un uso de CPU del {2}%" -f $servidor, $ip, $cpu)
      Write-Host "---------------------------------------------"
      $alertaCorreo = @"
      Aviso de Rendimiento Critico

      Administrador,

      Se ha detectado el siguiente problema en el servidor $servidor :
      - Direccion IP: $ip
      - Problema: El uso de CPU ha alcanzado el $cpu%.

      Solucionelo lo antes posible.
      "@

      Write-Host $alertaCorreo
   ```

7. **Limpieza y troceado de texto (Métodos ```.NET```)**

- Dada la siguiente línea extraída de un fichero de registro mal formateado:

   ```$lineaLog = "   error_critico;SRV-DB01;192.168.10.50;Puerto_3306   "```

- Elimina los espacios en blanco iniciales y finales (```.Trim()```).
- Reemplaza los guiones bajos ```_``` por espacios normales (```.Replace()```).
- Convierte todo el texto resultante a mayúsculas (```.ToUpper()```).
- Divide la cadena resultante usando el punto y coma ```;``` como delimitador (```.Split(';')```), guarda el resultado en ```$campos``` y muestra por pantalla únicamente el tercer elemento (la dirección IP).

   ```
      $lineaLog = "   error_critico;SRV-DB01;192.168.10.50;Puerto_3306   "

      $espacios = $lineaLog.Trim()
      $guiones = $espacios.Replace('_', ' ')
      $mayusculas = $guiones.ToUpper()
      $campos = $mayusculas.Split(';')

      Write-Host $campos[2]
   ```

8. Búsqueda de patrones (```-like```, ```-match```, ```-replace```)

Dada la cadena ```$codigoActivo = "SRV-2026-PROD-99"```:

Comprueba con ```-like``` si empieza por ```"SRV*"```.
Comprueba con ```-match``` si contiene algún dígito numérico (```"\d"```).
Usa ```-replace``` con la expresión regular ```"\d"``` para sustituir todos los números del código por el carácter ```"X"```.
   ```
      $codigoActivo = "SRV-2026-PROD-99"

      $like = $codigoActivo -like "SRV*"
      Write-Host "¿Empieza por SRV?: $like"

      $numeros = $codigoActivo -match "\d"
      Write-Host "¿Contiene algun digito numerico?: $numeros"

      $x = $codigoActivo -replace "\d", "X"
      Write-Host "Codigo modificado: $x"
   ```
