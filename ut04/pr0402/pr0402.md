7. **Limpieza y troceado de texto (Mรฉtodos ```.NET```)**

- Dada la siguiente linea extraida de un fichero de registro mal formateado:

   ```$lineaLog = "   error_critico;SRV-DB01;192.168.10.50;Puerto_3306   "```

- Elimina los espacios en blanco iniciales y finales (```.Trim()```).
- Reemplaza los guiones bajos ```_``` por espacios normales (```.Replace()```).
- Convierte todo el texto resultante a mayusculas (```.ToUpper()```).
- Divide la cadena resultante usando el punto y coma ```;``` como delimitador (```.Split(';')```), guarda el resultado en ```$campos``` y muestra por pantalla unicamente el tercer elemento (la direccion IP).

   ```

      $espacios = $lineaLog.Trim()
      $guiones = $espacios.Replace('_', ' ')
      $mayusculas = $guiones.ToUpper()
      $campos = $mayusculas.Split(';')

      Write-Host $campos[2]
   ```

- Comprueba con ```-match``` si contiene algun digito numerico (```"\d"```).

   ```

## Bloque 3: Operadores aritméticos y librería ```[Math]```
9. **Conversión de unidades y redondeo**
- Un servidor cuenta con ```$memoriaLibreMB = 3540``` (MB) de un total de ```$memoriaTotalMB = 16384``` (MB).
- Calcula el porcentaje de memoria libre mediante la fórmula ```($memoriaLibreMB / $memoriaTotalMB) * 100```.
- Utiliza la clase estática ```[Math]``` para mostrar ese porcentaje: redondeado al entero más cercano (```Round```), redondeado hacia arriba (```Ceiling```) y redondeado hacia abajo (```Floor```).
- Usa el operador módulo (```%```) para comprobar el resto de dividir ```16384``` entre ```1024```.
   ```
      $memoriaLibreMB = 3540
      $memoriaTotalMB = 16384

      $porcentajeLibre = ($memoriaLibreMB / $memoriaTotalMB) * 100
      Write-Host "Porcentaje libre: $porcentajeLibre %"
      Write-Host "----------------------------------------"

      $redondeoCercano = [Math]::Round($porcentajeLibre)
      $redondeoArriba  = [Math]::Ceiling($porcentajeLibre)
      $redondeoAbajo   = [Math]::Floor($porcentajeLibre)

      Write-Host "Redondeado al entero más cercano: $redondeoCercano %"
      Write-Host "Redondeado hacia arriba: $redondeoArriba %"
      Write-Host "Redondeado hacia abajo: $redondeoAbajo %"
      Write-Host "----------------------------------------"

      $restoDivision = $memoriaTotalMB % 1024
      Write-Host "El resto de dividir $memoriaTotalMB entre 1024 es: $restoDivision"
   ```

## Bloque 5: Tablas Hash, Objetos Personalizados y *Splatting*
13. **Creación y manipulación de Hash Tables**
- Crea una tabla hash llamada ```$fichaServidor``` con las claves: ```Hostname = "SRV-AD01"```, ```IP = "192.168.1.10"```, ```RAM_GB = 32``` y ```Critico = $true```.
- Modifica el valor de ```RAM_GB``` a ```64```, añade una nueva pareja ```SO = "Windows Server 2022"``` y elimina la clave ```Critico``` con ```.Remove()```.
- Recorre todas las claves de la tabla usando ```foreach ($clave in $fichaServidor.Keys)``` e imprime cada par ```Clave : Valor```.
   ```
      $fichaServidor = @{
         Hostname = "SRV-AD01"
         IP       = "192.168.1.10"
         RAM_GB   = 32
         Critico  = $true
      }

      $fichaServidor.RAM_GB = 64
      $fichaServidor.SO = "Windows Server 2022"
      $fichaServidor.Remove("Critico")

      foreach ($clave in $fichaServidor.Keys) {
         $valor = $fichaServidor[$clave]
         Write-Host "$clave : $valor"
      }
   ```
